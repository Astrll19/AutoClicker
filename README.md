Auto Clicker by Astryxl


CARA PAKAI (2 opsi):

 OPSI 1: Langsung jalankan (perlu Python) 
  Double-click: RUN.bat
  Atau: python AstryxlDesk.py

 OPSI 2: Build jadi .exe (sekali build, bisa dibagiin) 
  1. Double-click: BUILD.bat
  2. Tunggu 1-3 menit
  3. File .exe muncul di folder: dist\
  4. Nama file: "Auto Clicker by Astryxl.exe"
  5. .exe itu standalone — bisa dipindah/dibagikan ke PC lain
     tanpa perlu Python atau install apapun lagi

 REQUIREMENTS (untuk Opsi 1 / sebelum build) 
  pip install pynput pyautogui pillow pyinstaller

 HOTKEYS 
  F5 = Play / Stop
  F6 = Start / Stop Recording
  F7 = Emergency Stop

 FILE FORMAT 
  .axd  = format baru Astryxl Desk
  .nclick / .json = format lama (tetap bisa dibuka)
